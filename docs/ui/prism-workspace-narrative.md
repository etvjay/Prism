# Prism workspace narrative

## First read

A quiet operating surface, not a second landing page. The user sees where they are, what needs them, what they can do, and what has actually been observed.

## Action sequence

```text
relationship or request describes
-> policy and approval authorize
-> wallet executes
-> receipt proves
-> Activity reconciles
```

## Home composition

1. Compact status header.
2. Four plain-language actions.
3. Attention as the dominant work queue.
4. Relationships as the messaging entry point.
5. Private state and canonical context as truthful status, never invented values.
6. Recent Activity as evidence only.

## Motion intent

The navigation rail expands toward the content when the cursor or keyboard enters it. Labels resolve after icons, the active state remains anchored, and content views settle with one soft motion vocabulary. Motion explains spatial continuity and never implies a completed operation.
